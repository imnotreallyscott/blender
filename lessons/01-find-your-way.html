Lesson 1: Find your way around

About 12 minutes · Blender 5.2 LTS · Mac Mini + Magic Mouse · needs the Mac setup done first

Goal: Move the view, select the cube, and save a file.

What you should see

Open Blender. You'll see a gray cube, a light, and a camera. Leave them alone for now. The big center area is the 3D Viewport. This is where you build.

Steps

  1. Mouse Orbit the view. Hold Option and drag with the Magic Mouse. The cube should turn with the view. You are rotating the camera, not the cube.
  2. Mouse Zoom. Swipe on the Magic Mouse surface. Swipe toward you to zoom out.
  3. Mouse Pan. Hold Shift + Option and drag. The view slides sideways.
  4. Key Fixed views. Press 1 for front, 3 for side, 7 for top. If nothing changes, the Numpad setting is off. Go back to the Mac setup page.
  5. Tool Select the cube. Click the cube with the left mouse button. It gets an orange outline. Click empty space to deselect.
  6. Key Save. Press Cmd + S. Name the file lesson01.blend and save it in a folder you will remember.
Mac reminder: Blender uses Cmd where Windows uses Ctrl. Undo is Cmd + Z. Undo is your safety net, so use it freely.

Project: stacked "716" blocks

You will end with three cubes stacked near each other. Placement does not need to be neat yet.

  1. Tool Click the cube so it's selected.
  2. Key Press Shift + D. A copy appears and follows your mouse. Click once to place it. Press Esc instead if you want to cancel. (Blender's duplicate key is Shift + D. unverified on your Mac.)
  3. Key Repeat once more so you have three cubes.
  4. Check You see three cubes in the 3D Viewport.
  5. Key Save with Cmd + S.
