Goal: Make the Magic Mouse work for Blender's 3D view, and turn on the number-key setting.
You are done when:

Mac setup: Magic Mouse and Blender settings

About 10 minutes · do this once · Mac Mini + Magic Mouse

Why this step exists

Blender uses a middle mouse button to move around the 3D view. The Magic Mouse has no middle button. Blender has a setting that lets you do the same thing with Command + click. Turn it on once, and every lesson will work.

Steps

  1. Menu Open Blender. Click the Blender menu in the top-left of the screen, then choose Settings. unverified label for 5.2 Some versions use Edit > Preferences instead.
  2. Menu In the Settings window, open the Input section unverified.
  3. Mouse Turn on Emulate 3 Button Mouse. The Blender manual confirms this option exists and that it works with Alt + left click manual, Blender 5.2 LTS. Find the Modifier setting under it and choose OSKey. On your Mac, Command works with OSKey and Option did not. Leave the other options alone.
  4. Key Find Emulate Numpad unverified name in the same section and turn it on. This makes the top-row number keys (1, 2, 3, 7) change views and select modes, which later lessons use.
  5. Key Close the Settings window. Blender saves preferences automatically unverified.
  6. Check Press Shift + A in the 3D view. A menu should open. Press Esc to close it.
If a label is different: Blender moves settings between versions. Look for the setting by name in the Settings search bar at the top of the window, and tell me what it says so I can fix this page.
