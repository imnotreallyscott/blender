Lesson 5: Bevel and smooth

About 15 minutes · Blender 5.2 LTS · Mac Mini + Magic Mouse

Goal: Round hard edges with Bevel, then smooth the whole model with a Subdivision Surface modifier. Then build a rounded coaster.

Two tools that make models look finished

  • Bevel (in Edit Mode): rounds an edge into a small slope.
  • Subdivision Surface (a modifier): smooths the whole model. Your original shape stays the same. Only the look changes.
Modifier panel: select the object, then open the Modifier tab (the wrench icon) in the Properties panel on the right. unverified icon location in 5.2

Steps

  1. Tool Select a cube and press Tab for Edit Mode.
  2. Key Press 2 for edge select.
  3. Mouse Click one edge. It turns orange.
  4. Key Press Ctrl + B. Move the mouse slightly and click. Ctrl+B unverified on Mac
  5. Check The edge now has a narrow slope instead of a sharp corner.
  6. Key Press Tab to return to Object Mode.
  7. Menu Open the Modifier tab (wrench). Click Add Modifier, then Generate > Subdivision Surface. unverified menu names
  8. Key In the modifier, set Levels Viewport to 2.
  9. Check The cube looks soft and rounded, but the outline still matches the original shape.
  10. Key Save with Cmd + S.

Project: rounded coaster

A flat disc with rounded edges. Colors are your choice later.

  1. Tool Add a cylinder: Shift + A, then Mesh > Cylinder.
  2. Menu In the Adjust Last Operation panel (bottom left), set Vertices to 32 and Radius to 1. panel name unverified
  3. Key Press S, Z, type 0.15, Enter. It becomes flat.
  4. Key Press Tab, then 2 for edge select.
  5. Key Press A to select all edges.
  6. Key Press Ctrl + B, move slightly, click to round the edges.
  7. Key Press Tab. Add a Subdivision Surface modifier and set Levels Viewport to 2.
  8. Key Save as coaster.blend with Cmd + S.
