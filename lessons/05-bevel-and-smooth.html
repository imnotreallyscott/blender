Lesson 5: Bevel and smooth

About 15 minutes · Blender 5.2 LTS · Mac Mini

Goal: Round the hard edges with Bevel, then smooth the whole model with a Subdivision Surface modifier.

Two tools that make models look finished

  • Bevel (Ctrl + B, in Edit Mode): rounds an edge into a small slope.
  • Subdivision Surface (a modifier): smooths the whole model. It does not change your original mesh. It only changes how it looks.
Modifier panel: Select the object, then click the wrench icon in the Properties panel. Add modifiers from there. Panel names and icon positions can change between versions, so confirm the wrench icon location on your 5.2 install.

Steps

  1. Select a cube and press Tab for Edit Mode. Press 2 for edge select.
  2. Click one edge. Press Ctrl + B, move the mouse slightly, and click. The edge is now rounded.
  3. Press Tab to return to Object Mode.
  4. Open the wrench (Modifier) panel. Add a Subdivision Surface modifier. Set Levels Viewport to 2.
  5. Save with Cmd + S.

Project: rounded coaster

A coaster is a flat cylinder with rounded edges. It is a good first finished model. The colors are your choice. Blue and gold are a suggestion, not a requirement.

  1. Add a cylinder with Shift + A, then Mesh, then Cylinder. In the Adjust Last Operation panel, set Vertices to 32 and Radius to 1.
  2. Press S, Z, 0.15, Enter to make it flat, like a coaster.
  3. Enter Edit Mode with Tab. Press 2, then A to select everything, and press Ctrl + B. Move slightly and click to round the edges.
  4. Press Tab. Add a Subdivision Surface modifier and set Levels Viewport to 2.
  5. Save as coaster.blend.
