Lesson 14: Loop cuts for a head

About 14 minutes · Blender 5.2.1 LTS · Mac Mini + Magic Mouse

Why loop cuts matter

A cube has too few edges to make a head. A loop cut adds a ring of edges around the object. More rings give you more places to shape. Think of loop cuts as the "lines" a sculptor uses to plan a face.

Steps

  1. Tool Add a cube with Shift + A, then Mesh > Cube. Press S, X, type 1.2, Enter, to make it wider like a head. menu path unverified in 5.2.1
  2. Key Press Tab for Edit Mode, then 2 for edge select.
  3. Key Press Ctrl + R to start a loop cut. Move the mouse onto an edge that runs around the cube. A green line appears. Click to place it. Ctrl+R shortcut unverified on your Mac
  4. Check A new ring of edges goes around the whole cube.
  5. Key Repeat the loop cut twice more, so you have three rings in total.
  6. Mouse Switch to vertex select with 1. Hold the left mouse button on empty space and drag a box around one row of corners. Release.
  7. Key Press G, Y, and move the row forward to make a snout. Click to confirm.
  8. Key Select the top row and press G, Z to make a forehead. Press Tab to leave Edit Mode, then save as block-head.blend.
Why the row moves all together: a box-selected row is one unit. Moving it moves each corner the same amount. Keep moves small. You will refine the shape later.

Project: block head

A simple head shape with three rows. It's the base for the stylized animal in the next lessons. Save as block-head.blend.
