Lesson 3: Edit mode and vertices

About 14 minutes · Blender 5.2 LTS · Mac Mini + Magic Mouse

Goal: Enter Edit Mode, select corners (vertices), and change a shape. Then build a tilted shield plate.

Object Mode vs Edit Mode

Object Mode moves whole objects. Edit Mode changes the shape inside one object. Press Tab to switch. Press Tab again to switch back.

Steps

  1. Tool Select the cube in Object Mode by clicking it.
  2. Key Press Tab. Dots appear on the corners.
  3. Key Press 1 for vertex select.
  4. Mouse Click one corner dot. It turns orange.
  5. Key Press G and move the mouse. Only that corner moves. Press Esc to cancel.
  6. Mouse Box select. Hold the left mouse button on empty space and drag a rectangle around the top four corners. Release. Those four are selected.
  7. Key Press S, then type 0.5, then Enter. The top shrinks.
  8. Key Press A to select everything, then A again to deselect everything.
  9. Key Press Tab to return to Object Mode.
Common trap: If nothing moves, you are probably in Object Mode. Check the mode menu at the top left of the 3D Viewport. It should say Edit Mode.

Project: tilted shield plate

An original shield shape for later use. It is not a team logo. Start from a new cube.

  1. Tool Add a cube: press Shift + A, then choose Mesh > Cube. menu names unverified in 5.2
  2. Key Press Tab for Edit Mode, then 3 for face select.
  3. Mouse Click the top face to select it.
  4. Key Press Delete and choose Faces. The top is open now.
  5. Key Press 1 for vertex select. Select the bottom four corners.
  6. Key Press S, Z, type 0.1, Enter to flatten the bottom.
  7. Key Select the two bottom corners on the left, press G, Z, and move up a little. Repeat on the right side.
  8. Check The sides slope inward toward the bottom, like a shield.
  9. Key Press Tab to leave Edit Mode, then Cmd + S to save.
