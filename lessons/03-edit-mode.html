Lesson 3: Edit mode and vertices

About 14 minutes · Blender 5.2 LTS · Mac Mini

Goal: Switch into Edit Mode, select vertices, and change a shape by moving its corners.

Object Mode vs Edit Mode

Object Mode moves whole objects. Edit Mode lets you change the shape inside an object. Press Tab to switch between them. Press Tab again to go back.

The three select modes

  • 1 = Vertex (corner points)
  • 2 = Edge (lines between corners)
  • 3 = Face (flat surfaces)

Use the number keys on the top row. If they change the view instead, your Numpad emulation setting is on (see Lesson 1). Confirm on your machine.

Steps

  1. Select the cube in Object Mode, then press Tab to enter Edit Mode. You should see small dots on its corners.
  2. Press 1 for vertex select. Click one corner dot. It turns orange.
  3. Press G and move it. Only that corner moves. Press Esc to cancel.
  4. Press A to select everything. Press A again to deselect all. Use Alt + A to deselect as well (confirm this on your Mac).
  5. Select the top four corners with a box: drag a rectangle around them with the left mouse button held. Press S, then 0.5 and Enter to shrink the top.
  6. Press Tab to return to Object Mode.
Common trap: If nothing moves, you are probably in Object Mode. Check the mode dropdown at the top left of the 3D Viewport.

Project: tilted shield plate

This is an original shield-shaped plate for later use. It is not a team logo. Start from a fresh cube.

  1. Add a new cube with Shift + A, then Mesh, then Cube. Press Tab to enter Edit Mode.
  2. Press 3 for face select. Click the top face, then press Delete and choose Faces. You now have an open box.
  3. Press 1 for vertex select. Select the bottom four corners and press S, Z, 0.1, Enter to flatten them.
  4. Select the bottom two corners on one side and press G, Z, move up slightly. This creates a shield slope. Repeat on the other side.
  5. Press Tab to leave Edit Mode and save with Cmd + S.
